Informasi Klinis

Aplikasi ini menggunakan model machine learning untuk memprediksi risiko diabetes berdasarkan parameter-parameter medis. Model terbaik yang digunakan adalah RFE-RandomForest dengan akurasi tinggi.

Hasil prediksi disertai dengan penjelasan faktor-faktor yang mempengaruhi keputusan model menggunakan pendekatan SHAP (SHapley Additive exPlanations).
